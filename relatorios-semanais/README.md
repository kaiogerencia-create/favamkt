# Relatórios semanais — WhatsApp dos clientes

Resumo da semana que vai no grupo de cada cliente. Um arquivo por cliente,
dentro da pasta da data de envio.

## Clientes na rotina

| Cliente | Arquivo |
|---|---|
| Granblê | `granble.md` |
| Yamagata Sushi | `yamagata.md` |
| Gastronomia Simple | `simple.md` |
| Tia Mima | `tia-mima.md` |
| Pousada Chalés do Babaçu | `pousada-babacu.md` |

## Como usar

1. Copiar `TEMPLATE.md` pra uma pasta nova com a data de envio
2. Preencher os 4 blocos variáveis com as demandas da semana
3. Copiar o conteúdo do arquivo e colar direto no grupo do cliente

O bloco `🔁 ROTINA` é fixo e vai em todos, toda semana, sem alteração:

> Stories publicados todos os dias, e inbox e comentários respondidos.

## Origem do conteúdo

As demandas da semana saem do que foi produzido pra cada cliente. Hoje isso é
levantado no Drive (pastas de entrega de cada cliente) e conferido com o Kaio
antes de enviar — a pasta mostra o que foi produzido, não o que foi combinado,
então sempre passa por revisão humana antes de ir pro grupo.
